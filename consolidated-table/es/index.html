La tabla consolidada se arma sobre tu propio BigQuery. Detrics es lo que lo llena: conectás las cuentas de cada cliente, apuntás Detrics a BigQuery como destino, y sincroniza una tabla por plataforma todos los días, sola.

Apuntá Detrics a tu proyecto de Google Cloud. Escribe una tabla por plataforma en tu dataset y las mantiene sincronizadas todos los días.

Create Destination: conectá tu proyecto de Google Cloud como destino de BigQuery

Creá un Table Group

Un Table Group define el esquema de tus tablas. Elegí todos los campos de abajo, así tus tablas de Detrics llevan el detalle de campañas, las métricas y la imagen del creativo que necesita cada fila. Armá un Table Group para Meta y uno para TikTok. Los campos se llaman distinto en cada plataforma, así que esto es exactamente lo que tenés que tildar:

Meta Ads
  • Dimensiones: Date, Account Name, Campaign Name, Ad Set Name, Ad Name, Ad ID, Ad Image URL, Ad Video URL
  • Métricas: Amount Spent, Impressions, Inline Link Clicks
TikTok Ads
  • Dimensiones: Stat Time Day, Advertiser Name, Campaign Name, Adgroup Name, Ad Name, Ad Id, Creative Thumbnail Url, Ad Playable Url, Creative Preview Url
  • Métricas: Spend, Impressions, Clicks, Conversion, Likes, Engagements

Agregación temporal: Daily en las dos. Dejá el campo de cuenta (Account Name en Meta, Advertiser Name en TikTok): es lo que usa el mapeo de clientes para el join. Los campos de creativo se llaman distinto pero describen lo mismo, así que al consolidar los unís en una sola columna: el Ad Image URL de Meta y el Creative Thumbnail Url de TikTok pasan a ser creative_image_url.

Table Group: las dimensiones + métricas de arriba, agregación Daily

  2. Elegí el data source: la plataforma y la conexión/cuenta a sincronizar. Empezá con una sola cuenta para que la primera sincronización sea rápida; sumá las demás cuando funcione.
    Paso 1 · Source: elegí la plataforma y la cuenta
  3. Elegí el destino (tu proyecto y dataset de BigQuery).
    Paso 2 · Destination

Mapeá cada cuenta a un cliente un Google Sheet chico, leído en vivo por BigQuery

Las cuentas de anuncios en crudo no saben quién es el "cliente". Un cliente puede tener cinco cuentas en tres plataformas. Un Google Sheet chico lo resuelve: listás cada cuenta y el cliente al que pertenece, y BigQuery lo lee en vivo. Sumás una cuenta o renombrás un cliente y editás el Sheet, nada más.

client_map

Una fila por cada cuenta real de anuncios, mapeada al cliente que reportás. Encabezados de columna, exactos:

channelaccount_nameclient
Meta AdsACME_USAcme
Meta AdsACME_MXAcme
TikTok AdsAcme GlobalAcme
Meta AdsGlobex-MainGlobex
channel account_name client
client_map: cada cuenta de anuncios mapeada a un cliente (un cliente puede abarcar muchas cuentas y canales)
★ El account_name tiene que coincidir exacto con lo que reporta la plataforma (Account Name en Meta, Advertiser Name en TikTok). Esa es la clave que usa el join. Todo lo que dejes sin mapear igual entra en la tabla, solo que con el cliente en blanco.

Que BigQuery lea el Sheet

Para que la query de consolidación pueda hacer join con este mapeo, exponé el Sheet a BigQuery como una external table. Lee el Sheet en vivo, así cada edición aparece en la corrida siguiente sin ningún paso de exportación.

  1. En la consola de BigQuery, abrí tu dataset → Create table.
  2. Source: Drive. Pegá la URL del Sheet, formato Google Sheets, y poné el sheet range en la pestaña (por ejemplo client_map!A:C).
  3. Nombre de la tabla: client_map. Activá Auto-detect del esquema, poné Header rows to skip = 1 y creala.
✓ Este client_map es tu panel de control. Sumá un cliente o una cuenta en el Sheet y la próxima reconstrucción lo toma, sin tocar código.

Consolidá en una sola tabla uní todas las plataformas + agregá la columna de cliente

Detrics te da una tabla por plataforma. Esta query las apila en una sola tabla consolidated_ad_performance y hace join con client_map para que cada fila lleve su cliente. Los campos de creativo también se alinean acá: la URL de imagen de Meta y la miniatura de TikTok pasan a ser un mismo creative_image_url. Correla como scheduled query en BigQuery para que se reconstruya cada mañana, después de que entra la data.

Create a Table Group

A Table Group defines the schema of your tables. Pick the fields the consolidated table needs, the same for Meta and TikTok:

  • Dimensions: date, account name, campaign name
  • Metric: spend
  • Time aggregation: Daily

Build one for Meta and one for TikTok. On TikTok the date field is Stat Time Day and the account field is Advertiser Name. Include the account name: it's what the client mapping joins on later.

Table Group: date + account name + campaign name (dimensions), spend (metric), Daily aggregation

Create the mapping Google Sheet map accounts to clients, set budgets

Raw ad accounts don't know who the "client" is. One client can have five accounts across two channels. A tiny Google Sheet fixes that. Create a new spreadsheet with two tabs. The alarm reads it live, so you edit budgets or thresholds anytime and the next run picks them up.

Tab 1 · client_map

Map each real ad account to the client you report on. Column headers, exactly:

channelaccount_nameclient
Meta AdsACME_USAcme
Meta AdsACME_MXAcme
TikTok AdsAcme GlobalAcme
Meta AdsGlobex-MainGlobex
channel account_name client
client_map tab: each ad account mapped to a client (one client can span many accounts and channels)
Tab 2 · targets

One row per client, with the budget and how sensitive the alarm should be:

clientdaily_budgetmonthly_budgetswing_threshold_pct
Acme500015000030
Globex30009000025
client daily_budget monthly_budget swing_threshold_pct
targets tab: budget and sensitivity per client
  • swing_threshold_pct sets how big a move (%) triggers an alert. Set it to 30 and anything that moves 30% or more gets flagged.
  • monthly_budget drives the month-to-date pace check: whether you're over or under budget for the month so far.
★ This Sheet is your control panel. Change a budget or a threshold whenever the plan changes, and the alarm reads it on the very next run, without touching code.
